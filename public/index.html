初次安装与登录向导

              

                

                  

                    1. 安装官方 colab CLI
                    若尚未安装，推荐通过 uv 一键安装（或回退 pip3）；也可以复制命令到终端执行。
                  

                  

                    uv tool install google-colab-cli
                    
                  

                  

                    
                    
                  

                  

                


                

                  

                    2. 登录 Google Colab 账号
                    点击下方按钮会触发 colab --auth=oauth2 sessions 并打开系统浏览器完成授权；若偏好无头 ADC 认证，也可在终端运行 gcloud 命令。
                  

                  

                    
                  

                  

                    gcloud auth application-default login --scopes=openid,https://www.googleapis.com/auth/cloud-platform,https://www.googleapis.com/auth/userinfo.email,https://www.googleapis.com/auth/colaboratory

开卡自动初始化 & 缓存加速

              

                

                  

                    开卡后自动挂载 Google Drive
                    新建会话成功后自动运行 colab drivemount。
                  

                  
                

                

                  

                    启用 HuggingFace 高速下载 (hf_transfer)
                    自动安装 hf_transfer 并开启 HF_HUB_ENABLE_HF_TRANSFER=1，大幅加速生图/生视频大模型权重拉取。
                  

                  
                

                

                  

                    HuggingFace 缓存持久化到 Google Drive
                    自动将 HF_HOME 指向 /content/drive/MyDrive/.cache/huggingface，重开 VM 无需重复下大模型。
                  

                  
                

                

                  

                    自动安装 uv 加速包管理
                    确保远程 VM 已安装 uv，加快后续依赖安装速度。
                  

                  
                

                

                  

                    开卡后自动注入环境变量保险箱
                    将上方配置的环境变量自动写入新 VM 的 shell 配置。
                  

                  
                

                

                  

                    自定义启动脚本（Bash，可选）
                    每次初始化 VM 时在云端执行的额外命令（例如拉取仓库或启动后台服务）。
